## 7. Pre-session SAT homework

Before every SAT session after October 2, assign Taito a timed mini SAT section on the website.

Each assignment should:

* Be connected to a specific upcoming meeting.
* Contain approximately 12–18 questions.
* Take approximately 15–25 minutes.
* Prioritize skills where Taito previously struggled.
* Include a smaller number of mixed review questions.
* Save progress automatically.
* Grade objective questions automatically when submitted.
* Record each answer, correctness, skill, difficulty, and time spent.

Use deterministic answer-key grading for multiple-choice and numeric-response questions. AI must not decide whether an objective answer is correct.

## 8. Submission feedback and AI analysis

Immediately after submission:

1. Grade the assignment.
2. Save the result.
3. Generate student-facing feedback.
4. Generate more detailed tutor-facing analysis.
5. Create a new-submission alert for the tutor.
6. Prepare targeted in-session practice.

Student feedback should include:

* Overall performance
* Skills demonstrated well
* Two or three priority improvement areas
* Clear explanations for incorrect answers
* A short plan for the upcoming session
* Encouraging but honest language

Tutor analysis should include:

* Question-by-question results
* Error patterns
* Likely misconceptions
* Whether errors appear conceptual, procedural, careless, or time-related
* Suggested discussion points
* Recommended allocation of session time
* Targeted questions to review together

Do not send unnecessary identifying information to the AI provider. Use internal user IDs and only the information needed to analyze the assessment.

If AI generation fails, the scored results must still be available. Show “AI analysis pending” and provide a safe retry action.

## 9. Adaptive follow-up questions

For every missed question, prepare similar practice questions testing the same underlying skill and error pattern.

The new questions must:

* Test the same concept without merely changing names or numbers.
* Match or slightly increase the original difficulty.
* Include the correct answer and a step-by-step explanation.
* Be tagged to the original mistake and upcoming session.
* Avoid duplicating copyrighted question language.

AI-generated questions should be saved as tutor-review drafts. The tutor can approve, edit, replace, or remove them before the session. If no questions are approved, automatically use suitable questions from the reviewed question bank.

Do not use unreviewed AI-generated questions in the scored baseline diagnostic.

## 10. In-session lesson mode

Create a separate in-session view connected to each SAT meeting.

Its priority order should be:

1. Review missed homework questions.
2. Explain the relevant concept.
3. Complete approved, targeted follow-up questions together.
4. Review any questions where Taito was correct but unusually slow or uncertain.
5. Use the Hard Question Bank if time remains.

The tutor should be able to reveal answers and explanations one question at a time. Do not expose answers to the student before the tutor reveals them or before an independent assignment is submitted.

If Taito did not complete the homework, the in-session lesson should automatically use that homework as the session activity.

If Taito completed the homework and got every question correct, skip mistake review and prepare:

* More difficult questions in the same domains
* Questions from his broader historical weaknesses
* Hard Question Bank materials

For regular SAT sessions, organize the suggested 60-minute plan approximately as:

* 10–20 minutes: targeted math drill or review
* 40–50 minutes: Reading and Writing instruction and practice

For October 2, use the full diagnostic as the homework and prepare:

* 10 minutes: baseline results and progress review
* 50 minutes: Reading and Writing weaknesses and targeted questions

The tutor must be able to adjust the generated plan manually.
