Pre-session homework

Before subsequent sessions, Taito should receive a smaller SAT homework/assessment through the platform.

The workflow should be:

Assigned → Student completes → Auto-grade → Analyze → Tutor alerted → Student receives feedback → Session curriculum adapts

Student answers
Correct answers
Score

Explanations
Topic/skill classification
AI-generated or deterministic analysis
Recommended session focus

The student should receive useful feedback too, but tutor analysis can be more detailed.

Adaptive curriculum

For questions the student gets wrong, generate or select similar practice questions testing the same underlying concept.

These should become part of the in-session curriculum so the tutor and student can work through them together.

Do NOT simply reproduce copyrighted SAT questions.

Use original SAT-style questions or appropriately licensed/public material.

The session should therefore have two distinct areas:

Before Session

Homework / assessment completed independently.

During Session

Tutor-led material generated from:

Homework mistakes
Weak skills
Similar practice questions
Explanations
Additional hard questions if needed

If homework was not completed, the tutor should still be able to open that homework during the session and work through it with the student.

If the student completes everything and gets everything correct, provide a Hard Question Bank that tutors can use to fill remaining session time.

For every question, tutors and students should ultimately be able to see:

Question
Student answer where applicable
Correct answer
Explanation
Skill/topic
