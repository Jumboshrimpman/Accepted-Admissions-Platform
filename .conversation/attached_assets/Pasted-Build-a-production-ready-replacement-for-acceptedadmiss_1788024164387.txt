TIMED HOMEWORK EXPERIENCE
Show instructions and a “Start Test” button before revealing the assignment.
When the student starts:
* Record the server-side start time.
* Start the active timer.
* Reveal questions.
* Autosave responses to the database.
* Track active time.
* Track pause count and total paused time.
* Track time per question when practical.
Allow the student to pause.
While paused:
* Stop the active timer.
* Completely hide or unmount question text, passages, images, answer choices, and responses.
* Show only a neutral paused screen and “Resume Test” button.
* Prevent navigation through questions.
* Record the pause and resume times on the server.
When resumed:
* Reveal the assignment again.
* Continue the active timer.
Explain that hiding questions during a pause cannot technically prevent screenshots, another device, or outside materials.
Do not reveal correctness during the attempt.
Stop the timer when the student submits all questions. Require confirmation before final submission.
A page refresh or accidental disconnect must not erase answers. Calculate timing from server records rather than trusting only a browser timer.
PREDICTION-FIRST ENGLISH QUESTIONS
Add a configurable “Prediction First” mode for SAT Reading and Writing multiple-choice questions.
When enabled:
1. Show the passage and question without answer choices.
2. Require the student to predict the answer in their own words.
3. Allow the student to enter “IDK” when unsure.
4. Save and lock the prediction.
5. Reveal the answer choices.
6. Allow the student to select a final answer.
The prediction:
* Is not scored
* Is saved
* Cannot be edited after choices are revealed
* Is visible to the tutor
* Appears in the attempt review
* Can be compared with the final answer
Allow the tutor to turn this mode on or off for each question.

TARGETED FOLLOW-UP QUESTIONS
For incorrect answers:
1. Identify the tested skill and likely misconception.
2. Look for a reviewed follow-up question in the internal question bank.
3. If none exists and an OpenAI API key is configured, generate an original draft question testing the same underlying skill.
4. Generate a proposed answer and explanation.
5. Mark it as AI-generated and draft.
6. Require tutor review and approval before showing it to the student.
Do not simply change names or numbers in a copyrighted question. Create a genuinely original question based on the abstract skill.
If the student gets every question correct, select hard, reviewed extension questions from the same skills. If no reviewed question exists, generate draft extension questions for tutor approval.
